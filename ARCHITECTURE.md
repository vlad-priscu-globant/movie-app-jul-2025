## 2. Tech Stack Evolution & Architectural Architecture

The application is transitioning across 3 planned execution phases:

### Phase 1: SPA Foundation (Completed)
* **Core:** Vite 8 + Vue 3 (Composition API) + Tailwind CSS v4 + TypeScript 6 + Zod 4.
* **Routing & UI:** Vue Router 4 (`HomeView.vue`, `LoginView.vue`), layout shell (`App.vue`), and atomic presentation components (`MovieCard.vue`, `MovieListItem.vue`, `SearchBar.vue`, `NotFound.vue`).

### Phase 2: Full-Stack SSR Architecture & Cloud Persistence (Active - Session 05)
* **SSR Framework:** Nuxt 3 (SSR/SSG migration with `pages/`, `layouts/`, `components/`, `server/`).
* **Backend Layer:** Express Node API services for data fetching and aggregation (`src/api/` -> `server/api/`).
* **Cloud Infrastructure:** Supabase PostgreSQL Database for movie catalog & user data; Supabase Auth for JWT-based session security.

### Phase 3: Enterprise CI/CD & Agile Operations (Pending)
* **Deployment Target:** Vercel serverless functions & static CDN edge hosting.
* **Quality & Workflow:** GitHub Actions CI/CD quality gates, Git Flow branching model, Jira ticket integration, and simulated PR peer reviews.

## 3. Strict Architectural Directives

1. **Script Setup Syntax:** All Vue components MUST use `<script setup lang="ts">` exclusively.
2. **Absolute Type Safety:** Zero `any` types allowed. All API contracts, props, emits, and state primitives must be strictly typed via TypeScript interfaces or Zod schemas.
3. **Reactivity Isolation:** Direct DOM manipulation (`querySelector`, `getElementById`, `innerHTML`) is strictly prohibited. Use Vue `ref`, `reactive`, and template references.
4. **Unidirectional Data Flow:** Component state follows strict **Props Down, Emits Up**. Direct mutation of props inside child components is forbidden.

## 4. Nuxt 3 & Supabase Conventions

When refactoring or adding features in Phase 2:

### Nuxt 3 Conventions
* `pages/`: Page routes automatically generated by Nuxt router.
* `layouts/`: Shared layout wrappers (`default.vue`, `auth.vue`).
* `components/`: Auto-imported Vue components. Sub-folders create namespaced components.
* `composables/`: Auto-imported state logic & custom hooks (`useMovieCatalog.ts`, `useAuth.ts`).
* `server/api/`: Server-side endpoint handlers returning typed JSON responses.

### Supabase Integration Conventions
* **Client Initialization:** Use `useSupabaseClient()` or dedicated plugin initialization in `plugins/supabase.ts`.
* **Database Queries:** Perform server-side or composable-based data fetching with explicit error handling and type annotations matching database schema tables.
* **Authentication Guard:** Protect authenticated routes using Nuxt middleware (`middleware/auth.ts`) validating `useSupabaseUser()`.
